# 2026-11-21 自动授权与母子号管理

发布日期：2026-11-21（Asia/Shanghai）。

本次日期发布基于 `ebfd44b931cd33ece3a1592a3bc61d51919213d7`，汇总已验证并部署的功能；应用通用版本号仍为 0.2.1。

## 功能

- 协议批量登录支持代理档案、自定义代理、明确直连、母号团队与同出口并发选择，保留账号固定出口。
- 工作台本次成功授权默认自动保存到 Team48，支持关闭、失败重试和手动选择工作区，不自动上传密码或 2FA 密钥。
- 根据精确工作区 ID 与官方角色识别母号或子号；母号自动登记本地团队并同步成员，已登记子号按邮箱匹配。
- 保存授权后自动检查额度。后台任务支持限次重试、服务重启恢复和安全重试，工作台显示真实检查进度。
- 团队登记新增账密＋2FA 批量导入入口，复用已有协议登录流程。
- 未配置 Sub2API 时不读取远端代理目录，保留协议导入及本地出口选择。
- 保留个人空间、身份冲突、停用和已移除关系的保护，不把 Team 套餐或个人空间 Owner 当作母号。

## 稳定性与部署

- SSE 响应保留 `identity` 和 `no-transform`，避免中间层压缩转换授权事件流。
- 独立 Compose 配置允许通过环境变量控制 Turnstile 浏览器回退。
- Docker 构建忽略 macOS 元数据文件。
- 不改变数据库结构，不启用全局自动轮转或自动邀请，不修改其它项目。

已验证的容器部署保留以下配置；生产密钥、密码、数据库和 `.env` 不进入 Git：

```dotenv
TEAM48_BRIDGE_TURNSTILE_BROWSER_FALLBACK=true
TEAM48_BRIDGE_PLAYWRIGHT_BROWSERS_PATH=/ms-playwright
```

发布部署标记：`auto-followup-20261121-r2`。以上浏览器路径对应本项目 Docker 镜像，不是其它系统的通用本机路径。

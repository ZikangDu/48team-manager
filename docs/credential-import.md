# 导入已有授权凭据

在「账号与团队」点击「导入授权凭据」，或在「登记」菜单选择同名入口。

1. 选择 JSON/TXT 文件或粘贴已有授权 JSON，点击「预览授权」。
2. 核对邮箱、工作区、到期时间、当前账号状态及冲突提示。每个邮箱一次只能选择一个工作区。
3. 勾选确认后提交；已有账号保留团队关系、母号用途、代理和远端绑定，新邮箱建立本地待命档案。

支持标准令牌 JSON、GPTAuthBridge 导出、CPA、Sub2API OAuth 和 ChatGPT Session JSON。此入口不会接收密码／2FA 登录资料，也不会自动登录、加入团队或推送远端账号。

导入前检查邮箱、用户、工作区与客户端的一致性；JWT 解析不代表签名验证或官方测活。导入结果标记为等待官方验证，默认不会发起额度检查。账号由远端托管刷新、正在授权／刷新、被停用或归档时拒绝覆盖；预览后的账号变化也会阻止提交。

访问令牌、刷新令牌、ID token 和 Session 按一组整体替换；缺少的配套凭据会清除，避免混用旧授权。仅有访问令牌的导入会提示后续需要重新授权。

原始内容只用于解析，不写入浏览器存储。预览在服务端内存中加密暂存，15 分钟失效；关闭窗口会丢弃预览，服务重启后需重新解析。接口要求后台管理员会话，校验浏览器同源请求，成功和错误响应均禁止缓存。
